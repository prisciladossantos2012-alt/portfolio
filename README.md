# Priscila dos Santos · Product Portfolio

**Senior Product Manager · AI, B2B SaaS & Fintech**

Live site: **https://prisciladossantos2012-alt.github.io/portfolio/**

An interactive portfolio built as a single HTML file with WebGL (Three.js). 16,000 particles start as noise and reorganize into a new shape for each chapter of my career, from noise to signal.

## What's inside

- **Path**: global consulting → regulated fintech → B2B SaaS growth
- **Now**: the conversion surface of RD Station Marketing (TOTVS)
- **Regulated fintech**: case studies for Meus Sonhos (R$75M in savings), PayHop (R$1B+ in receivables), DDA and EmanaPay+
- **How I work**: an interactive go / pivot / stop simulator. Criteria are locked before the results are shown.
- **HealHub** and **agentic development**: building products with Lovable, GitHub and Codex
- Available in English, Portuguese and Spanish

## How it was built

Directed by me and built with an AI agent: concept, copy, custom GLSL shaders and the case-study structure. No build step, no framework, one file.
